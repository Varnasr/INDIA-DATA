Constituencies

    This page is in English only for now. Every figure on it is the Chief Electoral Officer's own, constituency by constituency, and each state's page says where it comes from.

    What each state published

    Four states published their rolls constituency by constituency, and each published different rolls. The table names the rolls behind each column. Only Uttarakhand published, for each constituency, how many names were added and how many removed after the draft. Everywhere else the change from the draft to the later roll is a net figure. It counts new voters as well as names put back, and it subtracts names removed after the draft, so it is the most that could have come back and says nothing about who.
