Constituencies

    This page is in English only for now. Every figure on it is the Chief Electoral Officer's own, constituency by constituency, and each state's page says where it comes from.

    Find a constituency

    Type the name of a constituency or a district. Every constituency with a figure anywhere on this site is here. Each figure is the count its own state's page leads with, in that state's measure, so a figure in one state cannot be set beside a figure in another. The link opens the constituency on its state's page.

      What each place counts

      The count behind every constituency in the finder, place by place. A state missing here published nothing by constituency, and its page works by district.

      Every constituency, against the roll it started from

      Each dot is one constituency, set against an earlier roll the state published by constituency. A dot left of the line ended the revision with fewer electors than that roll. The earlier roll is a different one in each state, so read each row on its own and do not set one state against another.

      After the draft

      The change from the draft to the later roll, for every 100 electors on the draft. In Tamil Nadu, Kerala and West Bengal it is a net figure, which counts new voters as well as names put back and subtracts names removed after the draft. It is the most that could have come back, and it cannot say who did.

      Uttarakhand, names added and removed

      Uttarakhand is the one state that published, for each constituency, how many names were added after the draft and how many were removed. A dot above the line is a constituency that removed more than it added.

      What each state published

      Each state published different rolls. The table names the roll behind each figure on this page.
