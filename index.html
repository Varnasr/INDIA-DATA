Electoral Integrity Metrics Explained

What These Technical Terms Mean:

Simpson's Paradox: When a pattern appears in different groups of data but disappears or reverses when the groups are combined. In Bihar, individual constituencies show pro-NDA deletion patterns, but this gets hidden when looking at state totals.

Jarque-Bera Test: A statistical test that checks if data follows a normal "bell curve" pattern. Natural administrative deletions should follow this pattern. Bihar's deletions fail this test, meaning they're artificially manipulated.

Z-Score: Measures how many "steps" away from normal something is. A Z-score above 3 means something happens less than 0.3% of the time naturally. We found 3,418 booths with Z-scores above 3 - statistically impossible without manipulation.

Correlation: Measures if two things move together. -0.52 correlation means when deletions go up, INDIA performance goes down consistently. This is a very strong relationship.

Plain-language explainers

Jarque–Bera (normality)

Checks whether residuals look roughly bell-shaped. It combines skewness (tilt) and kurtosis (tail weight). A small p-value (≤0.05) suggests non-normal; use robust inferences.

Breusch–Pagan (heteroskedasticity)

Asks whether residual spread changes with predictors. If significant, usual standard errors can be off; use robust (Huber–White) errors or model the variance.

Simpson’s paradox

An overall trend can flip inside subgroups (e.g., within ACs or urban/rural). Compare like-with-like before interpreting totals.

Causality caution

These are descriptive patterns. Without an identification strategy, treat associations as signals, not proof.
